# Development roadmap
**Baseline: October 27, 2026 · Original academic project: April 2021**

## 1. Recover reproducibility

Recover the original coordinate and cross-city inputs with provenance. Resolve notebook imports, paths, inline installation commands, and provider access.

**Acceptance:** a clean environment executes the documented preparation workflow with explicit data coverage and no embedded credentials.

## 2. Consolidate the analytical pipeline

Separate ingestion, validation, category aggregation, PCA, clustering, and mapping into reusable modules. Keep the original academic files as historical references.

**Acceptance:** a single documented command generates features, assignments, diagnostics, and a run manifest from permitted inputs.

## 3. Validate the method

Check city-qualified identifiers, geographic comparability, duplicate venues, missing coverage, normalization, feasible PCA sizes, and clustering stability.

**Acceptance:** meaningful tests cover malformed inputs and missing-provider responses; published diagnostics support the chosen configuration.

## 4. Build an exploratory comparison interface

Allow city and neighborhood selection, mapped clusters, category comparisons, and visible coverage dates. Explain similarity without implying verified commercial suitability.

**Acceptance:** users can inspect every comparison factor and export a traceable research shortlist.

## 5. Prepare portfolio evidence

Capture real outputs only after execution is reproducible. Use SS1_Overview.png, SS2_Neighborhood_Comparison.png, and SS3_Model_Diagnostics.png for the three main captures.

**Acceptance:** screenshots match the working version, contain no credentials or personal paths, and have captions identifying input vintage and model run.

## Future product direction

A separate business-location application could add demographics, transit, commercial rent, and adjustable scoring after data availability and rights are confirmed. That is a future scope decision, not a delivered capability of this archive.
